**Price:** Free (open source, AGPL-3.0)

## Overview
Server Suite turns your game panel into a proper Minecraft control panel. Server owners get mod
and plugin management, Modrinth modpacks, scheduled backups, one-click version and loader
switching, a config editor, player lists, Cloudflare subdomains and Discord/ntfy alerts, without
leaving the panel or asking you for help.

## Why hosts use it
- **Fewer tickets**: owners install mods, switch versions and restore backups themselves.
- **Safe by default**: a backup before every switch and mod change, rotation that never deletes
  the last good backup, refusals instead of half-finished changes.
- **Fits your plans**: per-server subdomain allowances and backup schedules, settable from
  Paymenter or any billing system through the API. Mod installs are never sold.
- **Respects permissions**: every page follows the panel's subuser permissions.
- **Light on your panel**: Wings downloads files straight to the server.

## Features
Mods & plugins · Modpacks · Backups with rotation · Versions & loaders · Automatic upgrades ·
Config editor · Server properties · Players · Errors & crash help · Bedrock crossplay · Velocity
networks · Subdomains & status cards · Notifications · Rust & Valheim · Billing API
