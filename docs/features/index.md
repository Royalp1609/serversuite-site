# Features

Server Suite adds pages to each server in the panel. Owners and subusers see a page only when
the server's game supports it and they hold its permission (see [Permissions](../admin/permissions.md)).

| Page | What it's for | Games |
|---|---|---|
| [Mods](mods.md) | Browse, install, update and remove mods and plugins | Minecraft Java |
| [Configs](configs.md) | Edit plugin and mod configs as a form | Minecraft Java, Rust, Valheim |
| [Modpacks](modpacks.md) | Install and update Modrinth modpacks | Minecraft Java (Fabric, Quilt, Forge, NeoForge) |
| [Backups](backups.md) | Scheduled backups with rotation | All |
| [Versions](versions.md) | Switch Minecraft version or server software | Minecraft Java |
| [Properties](properties.md) | `server.properties` as a form | Minecraft |
| [Players](players.md) | Whitelist, operators and bans | Minecraft Java, Rust, Valheim |
| [Errors](errors.md) | Grouped log errors and crash help | Minecraft Java, Rust, Valheim |
| [Crossplay](crossplay.md) | Let Bedrock players join a Java server | Minecraft Java |
| [Velocity](velocity.md) | Put servers behind a Velocity proxy | Minecraft Java |
| [Subdomains](subdomains.md) | Cloudflare subdomains and public status cards | All (status cards: Minecraft) |
| [Notifications](notifications.md) | Discord and ntfy alerts | All |
| [Rust & Valheim](games.md) | What those games get | Rust, Valheim |

Bedrock Dedicated Server gets Backups, Properties, Subdomains,
Notifications and an **Add-ons** page for behaviour and resource packs.
